Jouer sans connexion

Pas de réseau dans la salle ? Enregistrez les pages sur votre appareil avant la partie : elles fonctionnent ensuite sans internet.

Télécharger les cartons Télécharger le tirage
  1. Téléchargez la page pendant que vous avez encore du réseau.
  2. Le jour de la partie, ouvrez le fichier téléchargé (dossier Téléchargements) avec votre navigateur.
  3. Les cartons et les numéros tirés restent enregistrés sur l'appareil, même si vous fermez la page.

Conseillé sur ordinateur, surtout pour l'organisateur. Sur téléphone, certains appareils (notamment les iPhone) ouvrent mal les pages téléchargées : les joueurs peuvent plutôt ouvrir la page en ligne avant d'arriver, puis la garder ouverte.

Inviter les joueurs

Organisateurs : imprimez l'affiche et posez-la sur les tables. Les joueurs scannent le QR code avec leur téléphone pour obtenir leurs cartons.

lehahiah.fr/loto/

Comment ça marche

  1. Chaque joueur génère ses cartons et envoie ses codes à l'organisateur avant la première boule.
  2. L'organisateur lance le tirage et peut afficher la grille sur une télé ou un vidéoprojecteur.
  3. Les joueurs marquent leurs numéros en touchant les cases de leurs cartons.
  4. Quine, double quine ou carton plein ? L'organisateur saisit le code du carton pour vérifier.
Bonne partie !
